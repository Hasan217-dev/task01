Testing Checklist

1. Open the site (http://localhost:8000) or open `index.html` directly.
2. Verify navigation links scroll to sections.
3. Click each category tab in the menu — only matching product cards should show.
4. Click the favorite (heart) buttons — the icon should toggle and a toast appear.
5. Submit the contact form — toast should confirm and form should reset.
6. Resize viewport to check layout (mobile hamburger menu open/close).

Notes: This is a static demo; contact form does not actually send messages.
