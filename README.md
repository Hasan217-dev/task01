# Sift & Sprinkle — Bakery UI Demo

A small static website demo for a bakery and cake shop.

## What’s included
- `index.html` — main markup
- `index.js` — interactive UI behavior
- `style.css` — styling and layout

## Run locally
Quick options:

- Open the site and verify menu tabs filter items.
- Click heart buttons to see toast and toggle.
- Submit the contact form to see the demo toast and form reset.
- Resize the window to check responsive behavior.
